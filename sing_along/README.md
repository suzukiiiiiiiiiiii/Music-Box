# Sing Along

端末に入っている音楽を、歌詞を追いながら聴くための Android アプリ。
[muziki](https://github.com/hbtalha/muziki) と同じところを狙って作った別実装で、
muziki が下敷きにしている Musicolet の考え方 —— **キューを何本も持てる**、
**フォルダをそのまま辿れる**、**歌詞が再生に合わせて流れる** —— をなぞっている。

コードは共有していない。作りが似ているのは狙いが同じだから。

## 画面

下のバーで5つの面を行き来する。ミニプレイヤーはその上に常駐する。

- **曲** — 全曲。曲名・アーティスト・アルバム・追加順・長さで並べ替え
- **アルバム** — タイル表示
- **アーティスト** — 曲数とアルバム枚数つき
- **フォルダ** — 内部ストレージをそのまま辿る。取り込んでいない曲が入っている
  フォルダでは、その場で「探す場所」に足せる
- **プレイリスト** — お気に入りと、自分で作ったリスト

右上から検索・キュー・設定へ。

## キューが複数ある

Musicolet 由来の、このアプリで一番効く部分。

キューは5本あって、それぞれが自分の並びと「どこまで聴いたか」を覚えている。
切り替えても頭には戻らない。曲を長押しして「別のキューに追加」を選べば、
いま流れているものを止めずに次のキューを組める。

キューの画面では、上のチップで中身を覗くだけの切り替えができる。再生に載って
いるキューは並べ替えと1曲削除ができ、載っていないキューは「このキューに切り替え」
を押した時点で再生が移る。

## 歌詞

再生画面はジャケットと歌詞の2面で、画面をタップすると裏返る。

- 曲と同じ名前の `.lrc`(または `.txt`)が隣にあれば、それを読む
- 無ければ曲のタグに入っている歌詞を使う

時刻つき(`[00:12.34]` の形)なら、いま歌っている行が大きくなって自動でついて
いく。行をタップするとその時刻に飛ぶ。指でスクロールしている間は追従を止めて、
5秒触らなければまた追いかけ直す。

`[offset:+500]` は時刻から引く向きで解釈する。1行に時刻タグが複数あるとき
(`[00:10.00][01:10.00]サビ`)は、その回数ぶん行を作る。

時刻の無いただの歌詞テキストも、そのまま流し読み用に出す。

歌詞をネットから取ってくる機能は入れていない。muziki はスクレイピングで
取得するが、こちらは端末内で完結させている。

## 入っているもの

- バックグラウンド再生。通知バーとロック画面から操作でき、イヤホンのボタンも効く
- シャッフル、リピート(なし/全曲/1曲)、再生速度(0.75〜2倍)
- スリープタイマー(15/30/45/60/90分)
- 次に再生・キューの最後に追加・別のキューに追加
- プレイリストの作成、並べ替え(ドラッグ)、削除(横スワイプ)
- お気に入り
- 曲名・アーティスト・アルバムの検索
- 背景(ライト/ダーク/端末に合わせる)、真っ黒背景、アクセント色8種

## APK の作り方

GitHub Actions の **Build Sing Along APK** が push のたびに作る。実行結果ページの
下の Artifacts から `sing-along-apk` を取り、zip を解いて出てきた
`app-release.apk` をスマホで開けば入る(「提供元不明のアプリのインストール」の
許可が要る)。

手元で作る場合:

```bash
cd sing_along
./tool/prepare_android.sh          # android/ を生成して設定を流し込む
flutter build apk --release --no-shrink
```

`android/` はリポジトリに置かない。`tool/prepare_android.sh` が
`flutter create` で毎回生成し、`android_config/AndroidManifest.xml` で上書きして、
`MainActivity` を `AudioServiceActivity` 継承に書き換え、`minSdk` を 23 に上げる。

CI の Flutter は **3.35.7** に固定している。上げるときは、`just_audio_background`
と `permission_handler` が新しい AGP で通るかを先に見ること。

## 構成

```
lib/
├── main.dart                     起動と配線
├── theme.dart                    配色
├── utils.dart                    時間の表示など
├── models/
│   ├── song.dart                 1曲ぶんの情報と並べ替え
│   ├── lyrics.dart               LRC の解析
│   ├── play_queue.dart           キュー1本ぶん
│   └── playlist.dart
├── services/
│   ├── library_service.dart      端末を探してタグと歌詞を読む
│   ├── player_service.dart       再生と複数キューの持ち回り
│   ├── playlist_service.dart     プレイリストとお気に入り
│   └── settings_service.dart
├── screens/                      各画面
└── widgets/                      ジャケット、曲の行、ミニプレイヤー、歌詞
test/
├── lyrics_test.dart              LRC の解析と現在行の判定
└── library_test.dart             並べ替え・まとめ・検索・キューの保存
```

## つまずきそうなところ

**曲が1つも出てこない**
権限が拒否されている。設定 → もう一度探す、を押すと確認が出る。Android 13 以上は
「音楽とオーディオ」の許可が要る。

**フォルダ画面で「取り込んでいない曲があります」が消えない**
そのフォルダを押して「探す場所」に足すと取り込まれる。
`/storage/emulated/0` の `Music` `Download` `Podcasts` は足さなくても毎回見に行く。

**歌詞が出ない**
`.lrc` の名前が曲と一致しているかを確認する。`曲名.mp3` なら `曲名.lrc`。
タグに歌詞が入っている場合は、索引が古いと拾えていないことがあるので再スキャンする。

**歌詞が流れず止まったまま**
時刻タグの無い歌詞。その場合は全文をそのまま出すだけで、追従はしない。

**APK が大きい**
`--no-shrink` を外すと小さくなるが、`just_audio_background` のクラスが R8 に
削られて release ビルドだけ再生が始まらない不具合が知られている。動くほうを取っている。
